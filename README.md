# About

Most portfolios scroll from top to bottom through generic cards.

This one invites visitors to **experience an illustrated journal and engineering logbook.**

Created by **Mohammad Fazil Malek**, this portfolio transforms traditional showcases into a personal notebook-inspired experience where sections unfold like pages of a handcrafted journal. Built with React 19, TypeScript, GSAP ScrollTrigger, and Tailwind CSS, it blends organic physical motion, tactile typography, and honest engineering storytelling.
